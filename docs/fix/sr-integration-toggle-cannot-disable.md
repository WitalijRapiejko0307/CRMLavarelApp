# Fix: интеграцию с колл-центром SalesRender нельзя выключить в настройках

**Файл:** [`resources/js/Pages/Settings/Index.vue`](../../resources/js/Pages/Settings/Index.vue), функция `isToggleOn`  
**Статус:** реализовано (правка в `isToggleOn`; ассеты нужно пересобрать, `npm run build`)  
**Scope:** настройки → «SalesRender (CallCentr)» → тоггл `sr_enabled`. Те же симптомы у всех тогглов, которые уже сохранены как включённые (`digest_enabled`, `cc_round_robin` и др.).

## Симптом

Админ магазина открывает «Настройки», где `sr_enabled` включён, и нажимает тоггл «Включить интеграцию с колл-центром». Тоггл остаётся в положении «Включено». Сколько раз ни нажимай, выключить его в интерфейсе не получается.

Пока `sr_enabled = 1`, продолжают работать:
- `SyncSalesRenderJob` (каждые 5 минут);
- отправка новых заказов в SalesRender из `WebhookController`.

## Причина

Состояние тоггла на экране считает `isToggleOn` ([`Index.vue:1069`](../../resources/js/Pages/Settings/Index.vue)):

```js
function isToggleOn(key) {
    return (form[key] === '1') || (form[key] === '' && currentValues.value[key] === '1')
}

function toggleSwitch(key) {
    const next = isToggleOn(key) ? '' : '1'
    form[key] = next
}
```

Второе условие делает выключенное значение (`''`) неотличимым от «ещё не менял». Порядок событий при сохранённом `sr_enabled = '1'`:

1. Страница открыта: `form.sr_enabled = '1'`, `currentValues.sr_enabled = '1'`. Тоггл включён.
2. Клик: `isToggleOn` даёт `true`, поэтому `form.sr_enabled = ''`.
3. `isToggleOn` снова считает значение: `form === '1'` ложно, а `form === '' && currentValues === '1'` истинно, то есть опять «включено». Тоггл остаётся включённым.
4. Повторный клик снова ставит `''`. До `'1'` значение не доходит, и тоггл никогда не показывает «Выключено».

`currentValues` обновляется только в `onSuccess` после «Сохранить» (`save()`), поэтому до сохранения запасная проверка всегда срабатывает.

Выключение работает только случайно. `save()` берёт `form[key]`, и если там `''`, на сервер уходит пустое значение, а `TenantSettingController::update` для тогглов всегда записывает `''`. Но админ видит включённый тоггл и не понимает, что сохранять, или не нажимает «Сохранить». Серверная часть корректна: `settings.*` с пустой строкой превращается в `null`, `isset()` ложно, и в `tenant_settings` пишется `''`.

Серверный код проверен чтением. Баг в браузере в этой сессии не воспроизводился.

## Fix

`form` уже инициализируется из `props.current` (`f[key] = props.current[key] ?? ''`), поэтому запасная проверка по `currentValues` не нужна. Источник правды один: `form`.

```js
function isToggleOn(key) {
    return form[key] === '1'
}
```

Функция `toggleSwitch` остаётся без изменений. `toggleRoundRobin` сам вызывает `isToggleOn` и сразу сохраняет значение, после правки он тоже начнёт выключаться.

Проверить после правки: `currentValues` продолжают использоваться в `isVisible`, `select` и в сообщении о сохранённом значении, их не трогаем.

## Проверка

1. Включить `sr_enabled` и сохранить. Тоггл «Включено».
2. Нажать тоггл. Он сразу показывает «Выключено». Нажать ещё раз. Он снова «Включено».
3. Выключить и нажать «Сохранить». Перезагрузить страницу. Тоггл остался «Выключено».
4. В `tenant_settings` для тенанта: `key = 'sr_enabled'`, `value = ''`.
5. После выключения `SyncSalesRenderJob` для тенанта пишет в лог `SalesRender disabled or not configured` и ничего не делает. Новая заявка через `/api/webhook/lead` не отправляется в SalesRender, `external_id` не заполняется.
6. Повторить п. 2–3 для `digest_enabled` и `cc_round_robin`: они используют тот же `isToggleOn`.

## Что не входит в фикс

- Заказы, уже отправленные в SalesRender (`external_id` заполнен, статус «Позвонить»), после выключения интеграции перестанут обновляться. Их придётся вести вручную или включить интеграцию обратно.
- Токен, Company ID и Project UUID остаются в настройках. Это ожидаемо, они нужны при повторном включении.
